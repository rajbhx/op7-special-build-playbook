## Problem

bulk-deleting `.l2s.tmp_obj_*` files destroyed the ENTIRE object DB (`git log` -> "bad object HEAD", gc -> "failed to run repack")

## Root cause

objects are symlinks pointing at `.l2s.tmp_obj_*` data files — removing the temp files breaks every object, and git count-objects flags the dangling symlinks as garbage

## Solution

NEVER bulk-delete `.l2s.tmp_obj_*` in this repo; recover by deleting only broken symlinks (`find .git/objects -type l ! -exec test -e {} \; -delete`) then `git fetch origin`; verify with `git fsck --no-reflogs` + `git verify-pack`
