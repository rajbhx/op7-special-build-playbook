# C5 — am start with HomeActivity failed (Error type 3: activity does not exist)

## Problem

am start with HomeActivity failed (Error type 3: activity does not exist)

## Root cause

launcher activity is the Fenix delegate `.App`, and the package id is io.github.forkmaintainers.iceraven.op7 (not org.mozilla.fenix.iceraven.op7)

## Solution

resolve the launcher with `cmd package resolve-activity --brief -c android.intent.category.LAUNCHER <pkg>` before launching
