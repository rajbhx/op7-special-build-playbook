# D22 — alias URL http://127.0.0.1:8790/s rendered a blank page in Iceraven

## Problem

alias URL http://127.0.0.1:8790/s rendered a blank page in Iceraven

## Root cause

the alias file 's' has no extension; python http.server serves it as application/octet-stream, and Gecko refuses to render a binary blob as HTML — page fetches 200 but shows nothing, JS never runs

## Solution

always give fixture files a .html extension (or set MIME) — check Content-Type before relying on a local fixture; blank page + 200 = wrong MIME, not a browser bug
