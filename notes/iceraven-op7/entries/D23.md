# D23 — dumpsys gfxinfo <pkg> framestats showed 0 frames while the page was actively scrolling

**Section**: D. Measurement and transfer
**Keywords**: actively, activity, actual, appear, compositor-level, content, continuous, deltas, desired, dumpsys, framestats, gaps, gfxinfo, idle, jank, judge, latency, line, main, measurement, measures, motion, package, page, processes, ready, refresh, renders, rows, scrolling, showed, smoothness, surfaceflinger, transfer, webrender

## Problem

dumpsys gfxinfo <pkg> framestats showed 0 frames while the page was actively scrolling

## Root cause

gfxinfo measures only the main process; WebRender content renders in :tab_* and :gpu processes, so page frames never appear in the package's gfxinfo

## Solution

measure compositor-level smoothness with dumpsys SurfaceFlinger --latency '<pkg>/<activity>#0' (line 1 = refresh ns, rows = desired/actual/ready); only judge deltas during continuous motion (idle gaps are not jank)
