## Problem

intent-opened URL tab never ran JS (no beacons) and showed blank/frozen

## Root cause

cold start with VIEW intent restores the old session in front and adds the URL tab in the background; background tabs suspend JS timers/rAF until foregrounded

## Solution

foreground-only web tests: have the user paste the URL in the address bar (works reliably), or use the chooser route; don't expect the intent tab to run until it is the active tab
