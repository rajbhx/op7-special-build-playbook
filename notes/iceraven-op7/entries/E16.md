# E16 — skill installs/updates in restricted sandboxes can report failure after a successful install

**Section**: E. CI quality
**Keywords**: best-effort, cleanup, clone, code, exit, exit-code, failure, flipped, fresh-install, idempotent, installs, null, operation, pack, permitted, quality, re-run, report, restricted, rm, sandbox, sandboxes, skill, successful, temp, trap, true, updates, verified

## Problem

skill installs/updates in restricted sandboxes can report failure after a successful install

## Root cause

the EXIT trap's rm -rf on the temp clone hit "Operation not permitted" on git pack files; with set -e the trap failure flipped the exit code

## Solution

cleanup is best-effort (rm -rf ... 2>/dev/null || true); verified fresh-install + idempotent re-run both exit 0
