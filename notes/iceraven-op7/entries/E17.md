## Problem

the skill updater/installer were hard-wired to one skill name (op7-special-build)

## Root cause

update_skill.sh hardcoded SKILL_NAME; install_skill.sh installed a single skills/<name>

## Solution

updater now derives SKILL_NAME from its own directory (generic for any skills/<name>); install_skill.sh installs ALL skills/ dirs from the playbook (SKILL_NAMES override for subsets); verified fresh install of both skills + markers on the device
