# E9 — `git add -A` staged a 148 MB APK even though `.gitignore` listed `op7apk/`

## Problem

`git add -A` staged a 148 MB APK even though `.gitignore` listed `op7apk/`

## Root cause

gitignore does NOT support inline comments — `op7apk/  # comment` makes the whole line a pattern that never matches; only `#` on its own line is a comment

## Solution

move comments to their own lines; verify with `git check-ignore -v <path>` before committing large files
