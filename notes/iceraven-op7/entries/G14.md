## Problem

the op7-special-build skill that agents actually load (/root/.shared-skills/op7-special-build) was a static copy of the playbook repo's skills/op7-special-build — it could silently drift from the playbook source, so agents would re-derive stale knowledge

## Root cause

no updater, no version marker; the playbook repo auto-syncs its notes layer but nothing pushed the skill directory to installs

## Solution

bundled scripts/update_skill.sh into the skill itself — cheap git ls-remote check against the playbook HEAD vs a .skill-installed-commit marker; only on change does it sparse-fetch, validate SKILL.md, and atomically swap with a timestamped backup (restores on failure); offline/rate-limited keeps the current copy and warns; resolves ~/.codex/skills symlink to update the real root; PLAYBOOK_REPO/SKILL_ROOT/EXTRA_SKILL_ROOTS overrides for other machines; SKILL.md/quickstart/README/AGENTS.md now tell agents to run it at session start
