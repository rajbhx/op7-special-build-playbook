## Problem

conversations were only summarized by hand-written digests; raw chat knowledge was not systematically captured

## Root cause

session digests depend on the agent writing them; nothing read the actual Codex session files

## Solution

new local tool automation/op7/conversation_to_notes.py extracts ONLY useful typed knowledge (RULE/DECISION/REQUEST/GOTCHA/GOAL, trimmed ≤300 chars, newest-first, noise-filtered) from ~/.codex/sessions JSONL into docs/field-notes/conversations/; playbook sync fetches them and renders notes/<slug>/CONVERSATIONS.md; raw transcripts are never stored
