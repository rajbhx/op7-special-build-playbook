**Section**: A. CI & build pipeline
**Keywords**: absent, b10428, branch, build, checkout, clone, commit, default, depth, fails, fetches, git, gitlink, llama.cpp, origin, pipeline, release, shallow, submodule, tags

## Problem

llama.cpp submodule tag checkout fails in a shallow clone ('origin/b10428 is not a commit')

## Root cause

--depth 1 --branch <tag> fetches only the default branch, so release tags are absent

## Solution

submodule add shallow, then fetch --depth 1 origin tag b10428 + checkout + git add the gitlink
