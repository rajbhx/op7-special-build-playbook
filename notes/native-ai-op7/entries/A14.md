## Problem

ld.lld: undefined symbol ggml_threadpool_new / ggml_threadpool_free

## Root cause

threadpool API lives in the CPU backend (ggml-cpu.c), dlopen'd under GGML_BACKEND_DL=ON — not linkable from native-lib

## Solution

pin the calling decode thread before first graph compute; pthreads inherit creator affinity; no direct ggml-cpu link; -llog for logcat
