## Problem

Agent button crash: SQLiteException no such module: fts5

## Root cause

OP7 OxygenOS Android 10 SQLite lacks the FTS5 extension; MemoryDatabase.onCreate DDL failed and startSession ran outside try/catch -> uncaught coroutine crash

## Solution

detect FTS5 availability (try/catch DDL), fall back to bounded LIKE term-hit retrieval; wrap startSession/endSession so memory failure degrades gracefully
