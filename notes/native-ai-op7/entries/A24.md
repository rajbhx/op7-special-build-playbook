## Problem

remote quick-send/Agent showed ERROR 'generate failed: Flow exception transparency is violated' and produced zero tokens

## Root cause

OpenAICompatibleProvider emitted ModelStreamEvent.Error from a bare catch block AND emitted inside withContext(Dispatchers.IO) within the flow builder; kotlinx.coroutines 1.8 bans emit in a context different from the collection context (FlowExceptionTransparencyViolatedException), killing the whole stream

## Solution

stream() = flow { HTTP/SSE work }.flowOn(Dispatchers.IO) + .catch { emit(Error) } - never emit inside withContext/catch inside a builder; regression tests (unreachable endpoint -> Error event; local ServerSocket SSE stub -> tokens then Done); reproduced locally with kotlinc + kotlinx-coroutines-core-jvm + org.json jars before burning CI cycles
