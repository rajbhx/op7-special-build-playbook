## Problem

pm install -r -d -t failed INSTALL_FAILED_UPDATE_INCOMPATIBLE on every CI APK; certs drifted run-to-run (0b045c7c/64ced54c/7f721a2c) vs persistent 21add73b

## Root cause

AGP silently regenerated a random debug keystore each run despite the restored ~/.android/debug.keystore (JDK17 default keystore type is PKCS12 so a JKS fails to load; explicit signingConfig also failed to load it) - only the installed app's original key allows in-place update

## Solution

pragmatic, per user decision: accept the new signature - pm uninstall + pm install -t + restore model from /sdcard/Download/nativeai-model-backup.gguf via 'run-as com.engine.nativeai sh -c cat > files/models/model.gguf' (app uid CAN read /sdcard/Download); keep DEBUG_KEYSTORE_BASE64 restore + keytool validation in the workflow but do not gate builds on it
