## Problem

cannot push files (APK) to the device from the proot shell: proot /storage/emulated/0/1DMP is an ext4 image not visible to the device shell; proot /tmp differs; adb unusable (127.0.0.1:5555 timeout); SELinux blocks pm from reading /sdcard

## Root cause

proot rootfs is a separate filesystem; device shell sees the real /storage/emulated/0/1DMP (1DM download folder); host-bridge shizuku has no root

## Solution

python3 -m http.server 8000 --bind 0.0.0.0 inside a persistent exec session + device 'curl -o /data/local/tmp/x.apk http://192.168.1.3:8000/x.apk' + 'pm install -t /data/local/tmp/x.apk'; model restore via run-as cat from /sdcard/Download (verified READ_OK)
