## Problem

local model support was hardcoded to one fixed path (models/model.gguf) in nine EngineScreen call sites; multiple GGUFs were impossible and LocalModelProvider always exposed descriptor id local-llama

## Root cause

MainActivity registered one LocalModelProvider; UI built modelFile from a fixed path; provider descriptor was a constant, so per-file providers would collide

## Solution

LocalModelLibrary (pure JVM) scans models/*.gguf with stable ids (model.gguf -> local-llama, others -> local-<stem>); descriptor-override param on LocalModelProvider so each file gets its own provider sharing one NativeEngine; syncInto drops deleted files and keeps a local-llama placeholder when empty; LocalModelImporter (SAF) with progress + StatFs +64 MB margin + GGUF magic guard + temp rename; RemoteProviderBootstrap skips all local-* ids; picker '＋ Pick GGUF from storage…' row + size/quant subtitles; model card Delete; loadedPath guard reloads on model switch
