## Problem

pm install -r of the CI build failed INSTALL_FAILED_UPDATE_INCOMPATIBLE (signatures do not match) even though the workflow restores DEBUG_KEYSTORE_BASE64

## Root cause

the installed app predates the current persistent keystore value; the secret was rotated/replaced at some point, so the old and new debug keys differ

## Solution

one-time pm uninstall + reinstall (app data loss), re-stage the GGUF via run-as; future builds signed with the same secret update in place — verify with the next install before trusting 'persistent'
