# A45 — pushing code fix + docs back-to-back cancelled the code CI build

**Section**: A. CI & build pipeline
**Keywords**: back-to-back, build.yml, cancel, cancel-in-progress, cancelled, cancels, ci, code, concurrency, docs, finish, github-actions, group, head, latest, least, matters, pass, pipeline, previous, pushing, true, wait

## Problem

pushing code fix + docs back-to-back cancelled the code CI build

## Root cause

build.yml concurrency group build-<ref> with cancel-in-progress: true cancels the previous run on every push

## Solution

push code first, wait for its run to finish (or at least pass the build job) before pushing docs; only the latest HEAD build matters
