## Problem

KV-cache estimate used 28 layers / 2048 hidden for every model, overestimating the shipped Qwen2.5-1B (24/1024) by ~2.3x and understating maxSafeNctx

## Root cause

MemoryPlanner/MemoryBudget defaulted to 3B-class geometry and pre-flight runs before the model loads, so real geometry was never available

## Solution

GgufMetadataReader (strict GGUF v2/v3 header parse: architecture/block_count/embedding_length, null on any anomaly) + GgufMetaCache keyed by path/size/mtime; planner/budget take nullable layers/hiddenDim with labeled DEFAULT_LAYERS/DEFAULT_HIDDEN_DIM fallback; EngineScreen pre-flight passes measured values
