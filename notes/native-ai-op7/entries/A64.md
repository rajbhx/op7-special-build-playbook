## Problem

agent/generate loops and model init ran on the Main thread (llama decode, HTTP readLine, JNI init) — UI jank during every run; RuntimeMetrics was also written from multiple contexts

## Root cause

ViewModel scope used Dispatchers.Main.immediate and inherited it into run/collect/init; metrics object had plain fields

## Solution

runAgent/sendQuick launch on Dispatchers.Default (UI updates only via thread-safe StateFlows), ensureLocalLoaded wraps native init in withContext(Default), RuntimeMetrics methods @Synchronized (read from Main diagnostics, written off Main)
