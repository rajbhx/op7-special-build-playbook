# A65 — model-load state was contradictory: header showed COMPLETED right after load (loading is not a task result), and a failed re-init left the stale loaded flag true

**Section**: A. CI & build pipeline
**Keywords**: build, cleared, completed, contradictory, engineuistate.completed, engineuistate.ready, ensurelocalloaded, failed, failure, false, flag, header, init, left, loadedpath, loading, main, memory, model-load, native, null, pipeline, re-init, result, right, showed, stale, state, success, task, true

## Problem

model-load state was contradictory: header showed COMPLETED right after load (loading is not a task result), and a failed re-init left the stale loaded flag true

## Root cause

ensureLocalLoaded set EngineUiState.COMPLETED on success and never cleared _loaded on failure

## Solution

success -> EngineUiState.READY; failure -> _loaded=false + loadedPath=null; native init off Main
