## Problem

model manager had no integrity: downloads only checked the GGUF magic, so a corrupted file could load and silently produce garbage; no storage accounting

## Root cause

no checksum pipeline, no manifest

## Solution

ModelIntegrity (streaming SHA-256, IO) + ModelManifest (models/.manifest.json: sha256/bytes/url/ts) + downloader computes SHA-256 while streaming; ensureLocalLoaded refuses checksum mismatch; LocalModelLibrary.storageUsedBytes() drives a STORAGE line; manifest recorded on download and import
