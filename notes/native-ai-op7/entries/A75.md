# A75 — cancelled/interrupted GGUF downloads discarded the partial file, so large models had to restart from zero

**Section**: A. CI & build pipeline

## Problem

cancelled/interrupted GGUF downloads discarded the partial file, so large models had to restart from zero

## Root cause

ModelDownloader deleted .tmp on every failure path including cancel and network timeouts

## Solution

keep .tmp on cancel/IOException; next download() sends Range: bytes=N- and appends; SHA-256 replayed over existing bytes so the manifest checksum stays full-file; servers returning 200 (ignored Range) or 416 restart cleanly; UI shows 'paused — N MB cached; tap Download to resume' and a resume hint when a partial exists
