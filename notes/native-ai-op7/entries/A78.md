## Problem

source chunks were never written into the HNSW vector index, so the hybrid search was search-only plumbing

## Root cause

no chunk-id listing API and no ingest-time wiring; the embedding gate was always closed

## Solution

SourceStore.chunksForFile(fileId) (Android SQLite + JDBC twin + fake); SourceUpdater.indexChunksIfReady embeds + adds chunks at all five ingest paths only when index AND embedder report available (dormant until the EMBEDDINGS.md benchmark gate opens); ingest never fails on vector writes
