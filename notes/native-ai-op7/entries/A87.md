## Problem

installing a CI APK onto the OP7 from proot: /sdcard is isolated, shizuku forwards no stdin and shares no paths, argv base64 hits ARG_MAX

## Root cause

proot rootfs is isolated from the real Android filesystem; host-bridge shizuku only accepts a JSON command string

## Solution

python3 -m http.server bound to 0.0.0.0 in proot + shizuku sh -c 'curl -s -o /sdcard/...' (device and proot share wlan0); verify SHA-256 first
