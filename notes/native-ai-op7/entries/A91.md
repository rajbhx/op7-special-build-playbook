# A91 — web_search was a stub (LocalFallbackProvider) but the TOOL INVENTORY rendered AVAILABLE — a fake capability

## Problem

web_search was a stub (LocalFallbackProvider) but the TOOL INVENTORY rendered AVAILABLE — a fake capability

## Root cause

ToolRegistry.snapshot() only reflected AgentTool.available (default true); WebSearchTool never gated on a configured provider

## Solution

SearchProvider.configured (default true, fallback false); WebSearchTool.available = configured with unavailableReason; AgentTool/ToolDescriptor gained unavailableReason; inventory shows NOT CONFIGURED + reason line; web_search additionally reports OFFLINE when the network is down
