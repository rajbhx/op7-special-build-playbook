## Problem

user had no choice where memory/models live; paths were hardcoded to filesDir

## Root cause

MemoryDatabase('memory.db') fixed to app-private databases dir; EngineScreen/MainActivity hardcoded filesDir/models; no SAF path picker

## Solution

StoragePaths (dataDir/modelsDir/catalogFile/memoryDbPath/treeToAppPath/label) is the single resolution point; prefs gained dataDirOverride/modelsDirOverride; ENGINE SETTINGS → STORAGE rows with Internal/External/Pick (OpenDocumentTree, app-scoped only — scoped-storage honesty); models-dir changes apply live (library rebuild + VM re-attach), data-dir changes require restart (DB opened at startup)
